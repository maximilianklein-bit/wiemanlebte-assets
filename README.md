# wiemanlebte-assets

**Öffentliche Bildablage für den Instagram-Kanal „Wie man lebte".**

Dieses Repo hat genau einen Zweck: **Meta holt Karussellbilder über eine öffentlich
erreichbare URL selbst ab.** Reels lädt man direkt hoch, Karussellbilder nicht — ohne eine
solche URL lässt sich kein Karussell veröffentlichen.

Hier liegen **ausschließlich selbst gebaute Beitragsbilder**. Kein Kundenmaterial, keine
Archivbestände, keine personenbezogenen Daten.

**Die Quelle ist woanders.** Gebaut werden die Bilder im Arbeitsrepo aus HTML-Vorlagen;
was hier liegt, ist das Ergebnis. Wer etwas ändern will, ändert die Vorlage, nicht diese
Dateien.

## Aufbau

```
beitraege/<slot>/<nr>.jpg      z. B. beitraege/w1-di/01.jpg
```

Erreichbar unter `https://maximilianklein-bit.github.io/wiemanlebte-assets/<pfad>`.
